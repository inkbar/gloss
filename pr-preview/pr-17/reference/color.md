# Color

> An sRGB colour as #RRGGBB. Reference for Color in Gloss, a JSON format for PDF annotations.

An sRGB colour as #RRGGBB.

## Use it

```json
{
  "$ref": "https://gloss-format.org/schema/v1.json#/$defs/Color"
}
```

## Type

string; matches `^#[0-9a-fA-F]{6}$`
