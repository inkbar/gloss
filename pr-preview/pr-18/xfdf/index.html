Gloss and XFDF

XFDF is the XML format for PDF annotations, standardised as ISO 19444-1. Gloss carries the same annotations as JSON. This page lists the Gloss type for each XFDF element and the Gloss field for each XFDF attribute, generated from the names the schema records, so it matches v1.json.

Attributes on every annotation

Section titled “Attributes on every annotation”

Every element takes these. The element name gives the Gloss type.

XFDF Gloss Notes
name id
page page
rect rect XFDF writes it as x1,y1,x2,y2.
color color
opacity opacity
title author
contents contents
inreplyto inReplyTo
creationdate createdAt XFDF writes a PDF date string (D:20261019120000Z).
date modifiedAt XFDF writes a PDF date string.
subject subject
intent intent What a mark is for, such as a callout or an arrow (XFDF intent, PDF /IT).
none, an extension custom

<freetext>

Section titled “<freetext>”
XFDF Gloss Notes
none, an extension borderColor
width width
dashes dashes A dash pattern in points: lengths on, then off, repeating (XFDF dashes, PDF /D).
none, an extension cornerRadius
defaultstyle defaultStyle The keys are the CSS property names XFDF writes in its defaultstyle string, in camel case.
fringe fringe Insets from an annotation’s rect to the area it draws in, in points (PDF /RD, XFDF fringe, both in this order).
callout callout
head head The shape drawn at the end of a line (XFDF head and tail, PDF /LE).
