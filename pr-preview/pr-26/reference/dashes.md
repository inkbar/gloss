# Dashes

> A dash pattern in points: lengths on, then off, repeating (XFDF dashes, PDF /D). Reference for Dashes in Gloss, a JSON format for PDF annotations.

A dash pattern in points: lengths on, then off, repeating (XFDF dashes, PDF /D).

## Use it

```json
{
  "$ref": "https://gloss-format.org/schema/v1.json#/$defs/Dashes"
}
```

## Type

number[]; at least 1 item; each ≥ 0
