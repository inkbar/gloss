Circle

An ellipse inscribed in rect. XFDF element circle.

Use it

Section titled “Use it”

XFDF element: circle

Fields

Section titled “Fields”
Field Type Required Default XFDF Description
type string; always "circle" Yes — The annotation type. Always circle.
id string; at least 1 character Yes name Unique within the document. Never reused for a different annotation.
page integer; ≥ 0 Yes page The page the annotation is on, counted from 0.
rect Rect Yes rect The bounding box, in PDF user space.
color Color No color The annotation’s colour. Absent: the reader chooses the colour.
opacity number; 0 to 1 No 1 opacity Opacity, from 0 (invisible) to 1 (opaque). Absent means opaque.
author string No title Who made the annotation. Absent means unknown.
contents string No contents The annotation’s text, such as a comment or a note. Absent means no text.
inReplyTo string No inreplyto The id of the annotation this one replies to. Replies form threads. Absent means the annotation is not a reply.
createdAt string; format date-time No creationdate When the annotation was made, as an ISO 8601 date-time with an offset. XFDF writes a PDF date string (D:20261019120000Z). Absent means unknown.
modifiedAt string; format date-time No date When the annotation last changed, as an ISO 8601 date-time with an offset. XFDF writes a PDF date string. Absent means unknown.
subject string No subject A short label for what the mark is. Absent means no label.
intent Intent No intent What the mark is for, such as a callout or an arrow. Absent means the type’s plain form.
custom object No — Data of your own. Gloss readers keep it as it is and never interpret it. Absent means none.
width number; ≥ 0 No 1 width The stroke width in points. Absent means 1.
dashes Dashes No dashes The dash pattern of the stroke. Absent means a solid line.
interiorColor Color No interior-color The fill inside the shape. Absent means no fill.
